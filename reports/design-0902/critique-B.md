# exist 디자인 크리틱 — 평가자 B (시각 디자인: C.R.A.P. + 타이포·여백)

기준: 스크린샷 36장 중 desktop·mobile 전 화면 18장 + 의심 화면 tablet/laptop 5장(home-personal-tablet, schedule-week-tablet, files-tablet, hub-chat-laptop, orgchart-tablet) 실사. 대비·터치타겟·폰트 실측은 metrics.md와 겹치는 경우 "계측 확인됨"으로만 표기.

## 0. 교차 화면 공통 결함 (여러 화면에서 반복 — 개별 화면 섹션에서 재카운트하지 않음)

### [전역-tablet] 상단 마퀴 바 — 일정 아이템 3개 텍스트 겹침
- 원리: A (겹침) + R
- 심각도: **Major** — 텍스트가 물리적으로 겹쳐 판독 불가
- 결함: 768px에서 마퀴 바의 아이템 2·3("1라인 설비 점검", "방열판 시제품 검수")이 서로 위에 렌더링되어 "시작 8시간 **방**분 **뒤작** 내" 같은 합성 문자열이 보임. home-personal-tablet, schedule-week-tablet, files-tablet 3장 모두에서 동일 재현 — 화면 개별 문제가 아니라 마퀴 컴포넌트의 태블릿 브레이크포인트 결함.
- 수정안: 768px 이하에서 아이템 1개만 표시하고 나머지는 회전(rotate) 또는 "+2" 카운터로 축약.

### [전역] 사이드바 "그룹 입장" 카드 — 모든 화면에서 시각적 1순위 강탈
- 원리: C (위계)
- 심각도: **Major** — 8개 화면(orgchart 제외 전부)에서 반복되는 위계 오류
- 결함: 좌측 사이드바의 "그룹 입장" 카드는 채도 최고의 브랜드 그린 면적 355×135px + 흰 굵은 제목 + 흰 입력창 + "+" 버튼으로, 어느 화면에서든 본문 콘텐츠보다 시각적으로 무겁다. "코드로 그룹 참여"는 저빈도 작업인데 채팅·원장·파일 등 매 화면에서 첫 시선을 가져감. hub-chat-desktop에서는 진짜 1순위(대화)보다 이 카드가 먼저 읽힘.
- 수정안: 흰 배경 + 그린 아웃라인의 조용한 카드로 강등하고, 채운 그린은 "참여" 버튼 하나에만 남길 것.

### [전역] 카운트 뱃지 — 같은 개념에 최소 4가지 생김새
- 원리: R
- 심각도: Minor — 개념 학습 비용 증가
- 결함: "개수"라는 동일 개념이 (a) 히어로의 흰 배경 라운드 사각 "1건", (b) "지금 처리할 것 ②" 그린 원형, (c) 알림 벨의 빨강 원형 "3", (d) "결정 원장 2" 연그린 사각 pill, (e) 파일 모바일의 맨몸 빨강 텍스트 "0/3"로 화면마다 다르게 그려짐.
- 수정안: 의미 2종(중립 카운트=그린 계열 1형, 미처리 경고=빨강 1형)으로 뱃지 토큰을 통일.

### [전역] 아바타 색 — 같은 인물이 화면마다 다른 색 펭귄
- 원리: R
- 심각도: Minor — 인물 식별 단서가 화면 간 무효화됨
- 결함: 박민수·김소희 아바타가 home-org-desktop 통합 메시지에선 보라 배경 펭귄, hub-chat-desktop 말풍선 옆에선 회색 펭귄, files-desktop 확인 목록에선 보라/분홍. 헤더 우상단 내 아바타도 desktop 캡처(연그린)와 tablet/laptop 캡처(보라)가 다름. 아바타 색은 인물 고정값이어야 하는데 컨텍스트마다 재추첨된 것처럼 보임.
- 수정안: userId 해시 기반 고정 배경색 1개를 전 컴포넌트가 공유.

### [전역] 탭 콘텐츠 정렬 축 — 기록·설정만 중앙 협폭, 나머지는 풀블리드
- 원리: A + R
- 심각도: Minor — 탭 전환 때마다 콘텐츠 시작 x좌표가 점프
- 결함: 같은 허브 안에서 채팅·일정·공동편집 탭은 콘텐츠가 탭 영역 좌측 가장자리(x≈460)부터 시작하는데, 기록 탭은 x≈780, 설정 탭은 x≈800부터 시작하는 중앙 협폭 칼럼. 기록-desktop은 좌측에 ~320px 공백 기둥이 생기고 카드 좌변이 어느 화면 요소와도 정렬되지 않음.
- 수정안: 협폭 칼럼을 쓰더라도 좌측 정렬 기준선을 탭 콘텐츠 공통 x축에 맞추거나, 전 탭 중앙 정렬로 통일.

### [전역] 악센트 색 인플레이션 — 그린 브랜드에 빨강·주황·파랑·보라·노랑 동시 등장
- 원리: C
- 심각도: Minor — 색의 의미 체계가 성립 안 함
- 결함: 한 세션 안에서 빨강(마감 경고 "시작", 알림 뱃지, 미열람 점, 일요일), 주황(미확인 명단, "현장" 뱃지, 폴더 아이콘), 파랑(문서 아이콘, 토요일, 일정 카드 1종), 보라("중간관리" 뱃지, 아바타)가 모두 의미 부여 없이 병용됨. 특히 빨강이 "긴급"(작업 전 확인 필수)과 "단순 카운트"(알림 3)와 "요일"(일요일)에 동시에 쓰여 경고 색의 신뢰가 소모됨.
- 수정안: 빨강=차단·미이행 전용으로 격리하고, 요일·아이콘·뱃지는 중립 그레이+브랜드 그린 2톤으로 재배색.

## 1. login

### [login-desktop] 우측 폼 칼럼 전체
- 원리: 밀도 + A
- 심각도: Minor — 첫 화면의 균형 붕괴
- 결함: 1920px 중 좌측 960px은 채도 높은 일러스트로 꽉 차고, 우측 960px엔 320px 폭 폼 하나만 수직 중앙에 떠 있어 우측 상·하 각 ~400px이 순수 공백. 시각 무게가 좌측 100:우측 10 수준으로 기울어 로그인 폼이 부속물처럼 보임.
- 수정안: 일러스트:폼 비율을 60:40으로 줄이고 폼 칼럼에 최대폭 420px + 배경 톤 온 톤 카드를 부여.

### [login-desktop] 좌측 일러스트
- 원리: R (브랜드 일관성)
- 심각도: Minor — 브랜드 색과 무관한 첫인상
- 결함: 일러스트의 지배색은 하늘색 배경 + 파란 자물쇠 방패 + 남색 노트북으로, 우측의 브랜드 그린 CTA와 색 계열이 완전히 분리됨. 파란 자물쇠가 화면 최상단 중앙에서 가장 먼저 읽혀 "파란 서비스"로 오인됨.
- 수정안: 일러스트 배경·키 오브젝트를 브랜드 그린 틴트로 리컬러하거나 그린 듀오톤 처리.

### [login-desktop/mobile] 로고 락업 "o exist"
- 원리: 타이포 (자간·락업)
- 심각도: Cosmetic — 브랜드 오독
- 결함: 그린 링 심볼과 워드마크 "exist"의 간격이 글자 자간과 동일 수준으로 붙어 "oexist"라는 한 단어로 읽힘 (desktop·mobile 동일).
- 수정안: 심볼-워드마크 간격을 x-height의 0.5배 이상으로 벌리거나 심볼을 워드마크 위로 분리.

### [login-mobile] 하단 링크 2개
- 원리: P
- 심각도: Minor — 성격이 다른 두 액션이 동급으로 병렬
- 결함: "아이디/비번을 잊어버리셨나요?"(복구)와 "회원가입"(신규 진입)이 같은 12px 회색 밑줄 스타일로 화면 좌·우 끝에 붙어 있음. 회원가입은 로그인의 대안 경로인데 시각 위계가 0. 대비·타겟 크기는 계측 확인됨.
- 수정안: 회원가입을 텍스트 버튼(그린, 14px+)으로 승격하고 복구 링크만 보조 톤 유지.

## 2. home-personal

### [home-personal-mobile] 카드 내 마퀴 텍스트 — 어두(語頭) 잘림
- 원리: 타이포 (가독성)
- 심각도: **Major** — 핵심 정보(결정 제목)가 첫 화면에서 판독 불가
- 결함: "지금 처리할 것"·"보낸 결정 도달 현황"의 제목들이 마퀴 스크롤 중간 프레임으로 렌더링되어 "께를 3mm로 변경한다", "열판 두께를 3mm로 변경한다", "점검을 목요일 오전으로 옮긴다"처럼 문장 머리가 잘린 채 보이고, 잘린 좌측 경계에 페이드·말줄임 처리도 없어 레이아웃 버그처럼 보임. 원인은 좌측 플로팅 레일이 390px 중 ~70px을 차지해 본문이 ~310px로 압축된 것.
- 수정안: 모바일에서 제목 마퀴를 폐기하고 2줄 고정 + 말줄임으로 전환, 좌측 레일은 하단 탭바로 이동.

### [home-personal-mobile] 하단 플로팅 바 + 빨강 뱃지 "3"
- 원리: A (겹침) + P
- 심각도: Minor — 뱃지가 소속 불명
- 결함: 화면 하단 고정 바("주간 품질 회의 시작 8시간 54분 뒤")의 좌상단 모서리에 빨강 뱃지 "3"이 카드 라운드 밖으로 반쯤 걸쳐 있는데, 이 "3"이 그룹 아바타의 뱃지인지 바 전체의 뱃지인지 앵커가 불명확하고 카드 모서리 곡률과 충돌해 잘려 보임. 또한 이 바의 내용은 상단 히어로 요약과 중복.
- 수정안: 뱃지를 아바타 우상단 표준 위치(8px 겹침)로 고정하고 바 자체의 존재 이유를 재검토.

### [home-personal-desktop] 히어로 카드 색 — 유일한 다크 네이비 블록
- 원리: R (home-org와 교차 비교)
- 심각도: Minor — 같은 컴포넌트가 화면마다 다른 피부
- 결함: 개인 홈 히어로는 다크 네이비 슬레이트, 조직 홈(home-org) 히어로는 밝은 그린 그라데이션. 구조·카피 패턴("오늘 회의 N건 · …")이 동일한 같은 컴포넌트인데 배경 계열이 정반대라 워크스페이스 전환 시 다른 제품처럼 보임. 다크 네이비는 앱 전체에서 이 카드 한 곳에만 존재하는 고아 색.
- 수정안: 히어로 배경을 그린 계열 1종으로 통일하고 워크스페이스 구분은 아이콘·라벨로.

### [home-personal-desktop] 헤더 우측 대형 날짜 "9월 3일 (오전) 12시 7분"
- 원리: C + 타이포
- 심각도: Minor — 위계 경쟁 + 포맷 오류성 표기
- 결함: 헤더의 날짜·시각이 히어로 제목과 맞먹는 굵은 대형 타이포로 상시 노출되어 화면 1순위를 히어로와 양분함. 게다가 괄호 자리에 요일 대신 "(오전)"이 들어가 히어로의 "9월 3일 (목)"과 같은 날짜를 두 포맷으로 표기 — "(오전)"은 요일 슬롯에 있어 오독 유발.
- 수정안: 헤더 시계를 14px 레귤러로 강등하고 "9월 3일 (목) 오전 12:07" 포맷으로 통일.

### [home-personal-desktop] "보낸 결정 도달 현황" — 전원 확인 진행 바
- 원리: A
- 심각도: Cosmetic — 기준선 불일치
- 결함: "주간 정기 점검…" 행 하단의 그린 진행 바가 카드 내부 좌변에서 시작해 우측 "전원 확인" 라벨보다 한참 못 미친 지점(카드 내폭의 ~93%)에서 끝나, 100% 완료 상태인데 바는 미완처럼 보임. 우측 여백이 좌측(0)과 비대칭.
- 수정안: 100% 시 바를 행 콘텐츠 폭 전체로 채우거나 바 트랙(회색 배경)을 깔아 완료율을 명시.

### [home-personal-desktop] 좌측 사이드바 하부
- 원리: 밀도
- 심각도: Cosmetic — 데스크탑 공백
- 결함: 사이드바 콘텐츠가 y≈450에서 끝나고 이하 ~600px이 빈 흰 기둥. 우측 콘텐츠는 스크롤이 필요한 밀도인데 좌측 1/5은 방치됨.
- 수정안: 최근 그룹 목록 확장 또는 사이드바 폭을 280px로 축소해 콘텐츠에 양보.

## 3. home-org

### [home-org-desktop] "빠른 시작" 카드
- 원리: 밀도 + C
- 심각도: Minor — 데스크탑에서 휑한 저정보 블록
- 결함: 전폭 ~690px 카드 안에 작은 아웃라인 버튼 2개("새 그룹 만들기", "조직도 보기")만 좌측에 몰려 있고 우측 ~60%가 공백. 바로 아래 "팀 인사이트" 카드는 뷰포트 하단에 ~30px 슬리버로 잘려 제목만 반쯤 보임 — 접힌 건지 잘린 건지 판별 불가.
- 수정안: 빠른 시작을 우측 칼럼 상단의 버튼 행으로 격하하고 팀 인사이트를 첫 뷰포트 안으로.

### [home-org-desktop] 전체 일정 캘린더 — 요일 3색 체계
- 원리: C (악센트) + R
- 심각도: Minor — 팔레트 외 색 유입
- 결함: 일요일·과거 아님에도 6·13·20·27 전체가 빨강, 토요일 열이 파랑으로 착색. 빨강은 이 앱에서 "미이행 경고"(원장 카드, 미확인 명단)로 쓰는 색인데 캘린더에서는 단순 요일 표기라 의미 충돌. 파랑은 이 캘린더와 문서 아이콘에만 존재.
- 수정안: 주말은 회색 60% 톤으로 처리하고 빨강은 마감·경고 전용으로 회수.

### [home-org-mobile] 히어로 그린 위 그린 뱃지
- 원리: C (대비 구조)
- 심각도: Minor — 강조 장치가 배경에 흡수됨
- 결함: 그린 그라데이션 히어로 위에 카운트 뱃지 "0건"이 반투명 흰 배경+그린 텍스트로 올라가는데, 모바일에서는 뱃지 3개가 2줄에 걸쳐 줄바꿈되며 "할 일 / 0건"이 행 분리되어 라벨-값 쌍이 깨짐 ("마감 지난 할 일"과 "0건"이 다른 줄).
- 수정안: 라벨+뱃지를 `white-space: nowrap` 단위로 묶고 모바일 히어로는 항목당 1행 리스트로 전환.

### [home-org-desktop] 통합 메시지 목록 — 그룹·인물·AI 행 높이 리듬
- 원리: P
- 심각도: Cosmetic — 목록 리듬 불균일

- 결함: 다른 8개 화면은 좌측 사이드바+상단 마퀴+우측 유틸리티의 공통 셸인데, 조직도만 중앙 정렬 로고+"< 대시보드" 텍스트 백링크의 독립 페이지 셸. 로고 위치(좌→중앙), 복귀 수단(탭→백링크), 배경 구조가 전부 달라 외부 사이트로 이탈한 인상. 같은 정보 층위(조직)가 home-org 탭과 이 독립 페이지로 이원화된 것도 구조 혼란.
- 수정안: 조직도를 공통 셸 안의 탭/서브페이지로 수용하고 헤더 로고 좌측 고정.

### [orgchart-desktop] 헤더 액션 4버튼 — 3가지 버튼 문법
- 원리: R
- 심각도: Minor — 한 행에 아웃라인 문법 3종
- 결함: "가입코드 KWVV-99QL"·"초대 링크"는 그린 **점선** 보더, "관리 모드"는 회색 실선 보더, "역할 관리"는 그린 필드. 점선 보더는 앱 전체에서 이 두 버튼에만 존재하는 문법이고, 가입코드는 버튼인지 읽기 전용 코드 표시인지 형태로 구분 불가.
- 수정안: 코드 표시는 보더 없는 코드칩+복사 아이콘으로, 액션 버튼은 실선 아웃라인 1종으로 통일.

### [orgchart-desktop] "생산 1팀" 카드 고립
- 원리: 밀도 + A
- 심각도: Minor — 콘텐츠 폭 리듬 붕괴
- 결함: 상단 인사이트 카드와 하단 아코디언 3개는 전폭(~1040px)인데 그 사이 "생산 1팀" 카드만 ~340px로 좌측에 붙어 우측 700px이 공백. 부서가 1개뿐이어도 전폭 요소 사이에 낀 1/3폭 고아 카드는 그리드 이탈로 보임.
- 수정안: 부서 카드를 전폭 섹션 내 3열 그리드의 첫 셀로 배치해 빈 셀 자리를 시각화하거나 카드를 전폭으로.

### [orgchart-desktop] 하단 아코디언 3개 — 타이틀 중앙 정렬
- 원리: A + R
- 심각도: Minor — 앱 유일의 중앙 정렬 타이틀
- 결함: "전체 그룹"·"활동 기록"·"역할별 권한 안내" 바가 아이콘(좌측 고정)+타이틀(중앙)+캐럿(우측) 구조로, 타이틀이 자신의 아이콘에서 ~400px 떨어져 중앙에 떠 있음. 앱의 다른 모든 섹션 헤더는 아이콘+타이틀 좌측 인접인데 이 3개만 중앙 정렬이라 근접 원리와 전역 정렬 규칙을 동시에 위반.
- 수정안: 아이콘+타이틀 좌측 인접 정렬로 통일.
