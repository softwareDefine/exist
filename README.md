# exist (이그지스트)

**제조업 결정 전달의 누락과 왜곡을 차단하는 AX 플랫폼** — 결정이 사람이 아니라 조직에 남는다.

라이브: https://exist.sofie.co.kr · 시연영상: https://youtu.be/_DlglmOJzUY

---

## 무엇을 푸는가

본사·연구소·공장이 떨어진 제조 조직에서 결정은 본사 회의실에서 만들어지고, 현장은 메일 → 팀장 → 구두·카톡을 거쳐 결과만 받습니다. 그 과정에서 세 가지가 반복됩니다.

- **누락** — 회의에 없던 교대·야간·휴가자에게 결정이 닿지 않는다
- **왜곡** — 배경 없이 결과만 받은 사람이 같은 문장을 다르게 읽는다
- **확인 불가** — 누가 받았고 이해했는지 아무도 모른다 ("전달했다 vs 못 들었다")

기존 도구는 말한 것을 기록합니다. exist는 결정이 **도착했고, 이해됐고, 실행됐음을 증명**합니다. 그룹웨어·메신저(DX)가 전파할 공간을 주고 MES·QMS가 반영 이후의 실행을 기록한다면, exist는 그 사이 — 결정이 내려진 순간부터 현장에 도달해 이해되기까지 — 를 AI가 수행합니다(AX). 대체가 아니라 누구의 시스템도 책임지지 않던 마지막 구간을 메웁니다.

## 핵심 기능

| | | |
|---|---|---|
| **AI 회의 정리** — 통화·현장 녹음(TBM)이 끝나면 결정·할 일을 배경·기각 대안과 함께 자동 추출 | **결정 원장** — 모든 결정이 한 장부에, 작업 기준 변경은 "작업 전 확인 필수"로 표시 | **불참자 배달** — 회의에 없던 사람에게 결정을 배경과 함께 전달 |
| **수신 서명** — 폰 손가락 서명으로 확인을 남기고 이력 보관 | **리마인드 사다리** — 미확인자에게 AI가 자동 리마인드, 조장은 우리 조 미확인자를 한눈에 | **출근 브리핑** — 자리 비운 사이 미확인 결정을 출근 즉시 표시 |
| **결정 ↔ 문서 개정 연결** — 작업표준 개정에 근거 결정을 링크, 연혁·서명 이력 자동 | **안건 생애 추적** — 검토·보류·종결 이력, 조건 충족 시 AI가 보류 안건을 깨움 | **종결 사유 소환** — 닮은 안건이 올라오면 과거 결론과 이유를 자동 표시 |
| **교대 인수인계** — AI 초안 + 복명복창으로 이해 일치 확인 | **@AI 역질문** — 이해 안 되면 상사 대신 AI에게 근거와 함께 질문 | **조직의 기억(RAG)** — 쌓인 기록을 의미 검색, 출처 문서명과 함께 답변 |

같은 결정을 역할에 따라 다른 화면으로 봅니다 — 본사는 "내 결정의 도달률", 조장은 "우리 조에서 아직 안 본 사람", 현장 작업자는 "작업 전 확인할 것"만.

## 신뢰 가능한 AI 설계

원장에 가짜가 한 줄이라도 섞이면 제품 전체의 신뢰가 죽습니다. 환각을 구조로 막습니다.

- **추측 금지 + 근거 게이트** — 결정의 배경은 로그에 근거가 있을 때만. 날짜는 원문에 표현이 없으면 코드 레벨에서 폐기
- **화이트리스트** — 할 일 담당자는 참가자 명단 안에서만, 과거 날짜 거부
- **세션 스코핑** — 회의 정리 재료는 통화 세션 창으로 제한 (지난주 잡담 오염 차단)
- **재료 부족 시 AI 미사용** — 짧은 통화·녹음은 발언 원문을 규칙 기록 ("지어내지 않는다")
- **인간 감독** — 자동 기록된 결정엔 [취소], AI 할 일엔 [삭제], 안건 종결엔 사람의 사유 입력
- **전 AI 기능 규칙 기반 폴백** — API 장애 시에도 요약·브리핑·질의응답 동작
- **경량 RAG** — SQLite + 코사인 유사도, 임계 미달이면 "기록에 없어요"

## 구조 · 스택

```
client/   React + Vite + TypeScript (zustand, react-router) — 반응형 4단계, Capacitor(Android)
server/   Node 22 + Express 5 + Socket.IO + better-sqlite3
runner/   격리 코드 실행 컨테이너 (internal 네트워크, read-only, non-root)
deploy/   compose.prod.yml / compose.macmini.yml / nginx 설정
```

| 영역 | 기술 |
|---|---|
| 실시간 미디어 | mediasoup SFU 직접 구축 — 카메라·다중 화면공유, TCP 폴백(제한적 기업망) |
| 음성 | Web Speech 실시간 자막 + 용어집 교정 + 회의 후 Whisper 재전사 (현장 어휘 학습) |
| 동시편집 | Yjs + 커스텀 y-websocket (`/yjs/<room>`) — 문서·코드·시트·캔버스, 회람(열람 서명)·개정(rev)·서명 이력 |
| 한글 문서 | hwpx 서식 보존 열람 + 구형 hwp 본문 추출 자체 구현 → 인앱 열람·의미 검색 |
| AI | OpenAI API (`gpt-4o-mini` 기본) + 규칙 기반 폴백, 임베딩 RAG |
| 조직 관리 | 커스텀 역할(16개 액션), 부서 스코프 서버 강제, 계층 지정(본사/중간관리/현장), 감사 로그 |
| 인증 | scrypt, Bearer 세션(30일), 복구 코드 재설정 |

## 실행

### 개발

```bash
# 서버
cd server && cp .env.example .env   # OPENAI_API_KEY 입력 (없으면 규칙 기반 폴백)
npm ci && npm run dev               # http://localhost:4000

# 클라이언트
cd client && npm ci && npm run dev  # http://localhost:5173 (API·WS → 4000 프록시)
```

`/register`에서 가입 — 발급되는 **복구 코드**(XXXX-XXXX-XXXX-XXXX)가 비밀번호 재설정 수단이므로 보관 필수.

### Docker

```bash
docker compose up -d --build        # 앱(4000) + 격리 runner
```

환경변수(`OPENAI_API_KEY`, `ANNOUNCED_IP` 등)와 방화벽(UDP/TCP 40000–40100), HTTPS 요건은 [DEPLOY.md](DEPLOY.md) 참고. 화상회의는 HTTPS 필수(getUserMedia).

### 테스트

```bash
cd server && npm test               # 자동화 테스트 100+ (AI 추출 규칙·폴백·권한)
```
